VSCode一键窃取GitHub Token：IDE供应链安全盲区
HIGH ▼

Full Disclosure 披露了一个 VSCode 漏洞：攻击者可以一键触发 GitHub token 窃取，无需任何用户交互。这不是「理论上可能」，是已证明的攻击链。VSCode 现在是全球最多开发者使用的 IDE，它的扩展生态本质上是一个没有沙箱的代码执行环境——任何人发布的扩展都可以访问你的 token、文件系统和环境变量。

IDE 安全监控工具——扩展行为审计、token 泄露检测、VS Code 扩展沙箱——是一个几乎没人在认真做的方向。企业安全团队知道这个风险但没有好用的工具。如果你有 DevSecOps 背景，这里有一个很具体的产品空白。
